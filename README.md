# College Complaint & Grievance Management System

A Python-based Software Engineering mini project for registering, managing and tracking student complaints within a college.

## About
The system provides a structured way to record grievances related to ragging, bullying, harassment, discrimination and other college-related issues.

## Features
- Register complaints
- Anonymous complaint registration
- Generate unique complaint IDs
- View all complaints
- Search complaints by ID
- Update complaint status
- Store records using JSON

## Technology Stack
- Python 3
- JSON
- Python Unittest
- Git and GitHub

## Project Structure

- src/ - Python source code
- data/ - Complaint records
- docs/ - Project documentation
- tests/ - Automated test cases

## How to Run

Run the application:

    python3 src/main.py

Run automated tests:

    python3 -m unittest discover -s tests -v
